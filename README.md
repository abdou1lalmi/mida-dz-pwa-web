# MIDA DZ — Web PWA

An offline-ready recipe companion for Algerian cuisine, designed as a **digital field notebook** rather than a generic recipe catalogue. The experience combines regional storytelling, practical cooking guidance, multilingual support, and a tactile editorial interface.

## What this project demonstrates

| Focus | Implementation intent |
| --- | --- |
| **Product experience** | Home, discovery, saved recipes, detail views, and Cooking Mode are shaped around a short path from inspiration to action. |
| **Local-first behaviour** | Recipes, favourites, search, collections, and cooking flows are designed to remain useful when connectivity is limited. |
| **Inclusive interaction** | French, English, and Arabic content with RTL-aware layout, keyboard support, comfortable touch targets, and reduced-motion considerations. |
| **Visual direction** | Algerian gastronomic modernism with editorial typography, ceramic-inspired surfaces, restrained colour, and realistic food imagery. |

## Stack

`React` `TypeScript` `Vite` `Tailwind CSS` `PWA` `i18n` `RTL`

## Local preview

```bash
pnpm install
pnpm dev
```

## Product notes

The interface is intentionally calm and content-led. Saffron is reserved for active states and important actions, while regional coordinates, archive labels, and purposeful offsets make the collection feel documented rather than templated.

## Status

This repository is a design-led PWA implementation study focused on local-first product thinking, multilingual interface architecture, and premium editorial frontend craft.
